AI Gym Trainer — User Prompt Flows

This document shows only what happens when the user types different prompts — from greeting to workout coaching. No APIs or backend details.

Master flow — all prompt types

flowchart TD START([User sends a message]) --> TYPE{What kind of prompt?} TYPE -->|Greeting / small talk| G[Trainer replies warmly

and optional counts] TYPE -->|Muscle workout request| P[Trainer builds a plan

shows one card] TYPE -->|During workout| C[Trainer coaches step-by-step

Pattern 3 — Single muscle with explicit count

Examples: "5 chest exercises", "20 shoulder exercises", "Give me 3 bicep moves"

flowchart TD U[User: 5 chest exercises] --> C[Trainer reads exact number: 5] C --> S[Fetches exactly 5 chest exercises] S --> CAP{Number very large?} CAP -->|e.g. 100| MAX[Caps at 30 per muscle] CAP -->|normal| OK[Uses exact count] MAX --> R[Summarizes plan + cards] OK --> R

Pattern 4 — Multiple muscles, no counts (15 split across groups)

Examples: "Chest and back workout", "Shoulder, chest and legs"

flowchart TD U[User: chest and back workout] --> M[Trainer lists all muscles mentioned] M --> SPLIT[Splits 15 total across groups] SPLIT --> E1[e.g. chest: 7 exercises] SPLIT --> E2[e.g. back: 8 exercises] E1 --> R[One combined plan + 15 cards] E2 --> R R --> Q[Offers to start first exercise]
User prompt Split (default 15 total)
Chest and back7 chest + 8 back
Shoulder, chest and legs (3 groups)5 + 5 + 5
Two groups (generic)7 + 8 (remainder to last group)

Pattern 5 — Multiple muscles with explicit counts

Examples: "5 chest and 3 hamstring", "10 shoulder, 10 chest and 10 leg"

flowchart TD U[User: 5 chest and 3 hamstring] --> A[Trainer aligns counts to muscles in order] A --> G1[Fetch 5 chest] A --> G2[Fetch 3 hamstring] G1 --> T[Total: 8 exercises] G2 --> T T --> R[Summarizes both groups + 8 cards]
User prompt Counts Total exercises
5 chest and 3 hamstring5 + 38
10 shoulder, 10 chest and 10 leg10 + 10 + 1030
10 shoulder and some back10 explicit + remainder for back15
3 bicep and 3 tricep3 + 36

Order rule: First number maps to first muscle, second to second, and so on.

Pattern 8 — One specific exercise by name

Examples: "I want to do barbell curls", "Show me push-ups", "Let me do bench press"

flowchart TD U[User: I want barbell curls] --> F[Trainer looks up that exact name] F --> FOUND{Found in database?} FOUND -->|yes| ONE[Returns 1 exercise + steps] FOUND -->|no| NONE[Says not found;
suggests another name or muscle plan] ONE --> CARD[1 exercise card]

Barbell curls / push-ups / bench press1 matching exercise + coaching steps

Pattern 9 — Coaching during the workout (no new plan)

After a plan exists, user guides pace through the list the trainer already has in memory.

flowchart TD PLAN[Plan already loaded in conversation] --> START[User: start first exercise] START --> W1[Trainer walks through exercise 1 step by step] W1 --> NEXT{User says} NEXT -->|next / yes / done| W2[Trainer moves to next exercise] NEXT -->|repeat / again| W1 NEXT -->|skip| W3[Trainer skips to following exercise] NEXT -->|last exercise| WL[Trainer describes final exercise in plan] W2 --> NEXT W3 --> NEXT WL --> FIN[User: I'm done / stop / finish] FIN --> END[Trainer congratulates;
offers a new workout]

no repeats from last 7 days] P2 --> SHORT{Not enough unique left?} SHORT -->|yes| FB[Pulls from other difficulty levels] SHORT -->|still short| REP[May repeat old names to meet count]
